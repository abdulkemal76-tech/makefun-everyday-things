Entry for the make.fun bounty [Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479).

`main.py` (Python 3.13, standard library only) writes two lines to `/output/entry.txt`:

1. Line 1 explains one everyday thing, a traffic jam, to a 10-year-old in a single vivid sentence built on an analogy.
2. Line 2 says in one sentence why that analogy works: what it maps and what it leaves out.

Run it with:

```sh
python3 -P -s main.py
```
